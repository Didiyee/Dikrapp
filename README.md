# صلاتي وذكري 🕌 — Prayer Times, Adhkar & Quran

React + Vite + Tailwind CSS (RTL عربي كامل) + Capacitor (Android).

## ▶️ التشغيل على الكمبيوتر
```powershell
npm install
npm run dev
```
ثم افتح `http://localhost:5173`

## 📱 تشغيل التطبيق على هاتفك عبر GitHub + Obtainium (الطريقة المطلوبة)

الفكرة: GitHub يبني لك ملف APK تلقائياً، وتطبيق **Obtainium** على هاتفك يثبّته ويحدّثه.

### الخطوة 1: ارفع المشروع إلى GitHub (من الكمبيوتر)
```powershell
git init; git add -A; git commit -m "salati app"; git branch -M main
git remote add origin https://github.com/USERNAME/salati-dhikri.git
git push -u origin main
```
> استبدل `USERNAME` باسم حسابك. أنشئ المستودع من موقع github.com/new أولاً (اختر Public).

### الخطوة 2: ابنِ نسخة APK (مرة واحدة لكل تحديث)
```powershell
git tag v1.0
git push origin v1.0
```
- اذهب لصفحة المستودع ← تبويب **Actions** ← ستعمل مهمة `release-apk` (~5 دقائق)
- بعد انتهائها: تبويب **Releases** ← ستجد `v1.0` ومعه ملف **salati-dhikri.apk** جاهزاً
- لكل تحديث جديد: غيّر الرقم (`v1.1`, `v1.2`...) وأعد الأمرين

### الخطوة 3: ثبّت Obtainium على هاتفك
1. من متصفح الهاتف افتح: **obtainium.im** وحمّل التطبيق وثبّته
2. افتح Obtainium ← زر **+ إضافة تطبيق** ← الصق رابط مستودعك:
   `https://github.com/USERNAME/salati-dhikri`
3. اضغط **إضافة/تثبيت** ← سيحمّل الـ APK من الـ Release ويثبّته
4. عند إصدار نسخة جديدة (`v1.1`...): يصلك إشعار تحديث داخل Obtainium بضغطة واحدة
5. اسمح بـ"التثبيت من مصادر غير معروفة" عند طلب الهاتف ذلك

### طريقة بديلة سريعة (بدون APK — للتجربة الفورية)
1. وصّل الهاتف والكمبيوتر على **نفس الواي فاي**
2. شغّل: `npm run dev:phone`
3. افتح رابط الشبكة من متصفح الهاتف ← «إضافة إلى الشاشة الرئيسية»

## 🕰️ تعديل المواقيت يدوياً (الجديد — أسهل)
- **الإعدادات ← تعديل المواقيت يدوياً**: لكل صلاة ترى الوقت **التلقائي** وتحته حقل وقت — اكتب الوقت الدقيق الذي تريده (مثال `05:15`)
- اترك الحقل فارغاً ليبقى تلقائياً، وزر ↺ يرجع صلاة واحدة للتلقائي
- أي وقت مكتوب يُستخدم فوراً في: الشاشات، العد التنازلي، الأذان، التنبيهات
- الجدول الشهري يعرض دائماً الأوقات الفلكية التلقائية

## 📖 القرآن الكريم كاملاً — حفص وورش
- تبويب **القرآن**: قائمة السور الـ114 (بحث بالرقم أو الاسم)
- 📜 **رواية حفص عن عاصم** (رسم عثماني) و📜 **رواية ورش عن نافع** — زر تبديل في الأعلى، والنص الكامل لكلتا الروايتين
- تكبير/تصغير الخط، البسملة تلقائياً
- 🔊 التلاوة: حفص — مشاري العفاسي (آية آية أو السورة كاملة)، ورش — ياسين الجزائري (السورة كاملة)
- 🔖 **أكمل القراءة**: اضغط أي آية لحفظ موضعك والعودة إليه (مع الرواية)
- ⬇️ **تحميل المصحف كاملاً**: زر واحد يحفظ السور كلها للقراءة **دون إنترنت** (لكل رواية على حدة)

## 🔊 الأذان
- الإعدادات ← **صوت الأذان**: تفعيل/تعطيل، (مكة/المدينة/الأقصى/رابط mp3 مخصص)، مستوى الصوت، زر **تجربة**
- يُشغَّل تلقائياً عند دخول وقت أي صلاة مفعّلة (المس الشاشة مرة بعد فتح التطبيق ليسمح الهاتف بالتشغيل)
- ملاحظة: العمل في الخلفية والشاشة مغلقة يتطلب إضافة Native لاحقاً

## ⚙️ أوامر مفيدة
| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل للتطوير |
| `npm run dev:phone` | تشغيل + تجربة على الهاتف عبر الواي فاي |
| `npm run build` | بناء نسخة الإنتاج |
| `npm run cap:sync` | بناء الويب ومزامنته مع مشروع أندرويد |
| `npm run android` | فتح مشروع أندرويد في Android Studio |
